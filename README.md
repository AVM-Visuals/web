# avm-visuals.cz

Web AVM Visuals s.r.o. s prolinkem na AVM Atelier.

- `index.html` – celý web (Visuals + Atelier, 4 jazyky), obrázky jsou vložené přímo v souboru
- `ochrana-osobnich-udaju.html` – zásady ochrany osobních údajů
- `netlify.toml` – nastavení hostingu na Netlify
- Formuláře „poptavka-visuals“ a „rezervace-atelier“ zpracovává Netlify Forms

Soubory generuje Claude z pracovní verze; ruční úpravy přímo tady se při další aktualizaci přepíšou.
